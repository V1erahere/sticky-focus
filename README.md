# Sticky Focus 🗒️

A tiny always-on-top Pomodoro timer that lives on your desktop as a sticky note.

**Features:** tasks · subtasks · focus timer · themes · stamps

## Run from source

```bash
npm install
npm start
```

> Requires [Node.js](https://nodejs.org) and npm.
